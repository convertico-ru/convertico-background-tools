# Release checklist

## Before v0.1.0

- [ ] Repository is public
- [ ] About description and website are filled in
- [ ] Topics are added
- [ ] Social preview is uploaded
- [ ] README links work
- [ ] Chrome extension loads unpacked without errors
- [ ] Context menu appears only on images
- [ ] Selected image downloads successfully in a normal HTTPS case
- [ ] Convertico Background Remover opens
- [ ] WordPress plugin activates without PHP warnings
- [ ] Media Library action appears for image attachments
- [ ] GitHub Private Vulnerability Reporting enabled

## After release

- [ ] Create Git tag `v0.1.0`
- [ ] Publish GitHub Release
- [ ] Open one real roadmap issue rather than fake activity
- [ ] Record GSC baseline
- [ ] Start implementation of the remote-open endpoint
