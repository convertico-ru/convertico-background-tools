# Search visibility experiment

This repository is a product/integration project first. The SEO experiment is to measure whether a genuine external developer footprint coincides with improved non-brand visibility for the corresponding Convertico.ru tool page.

## Primary page

https://convertico.ru/remove-background/

## Baseline

Record a 28-day baseline in Google Search Console before external promotion:

- page impressions
- page clicks
- average position
- query-level impressions and positions

Keep screenshots or CSV exports.

## Query set

Track a stable query set such as:

- удалить фон
- убрать фон
- удалить фон онлайн
- удалить фон с фото
- удалить фон с фото онлайн

Do not change the query set midway just because some queries perform better.

## Intervention log

Keep a dated list of material changes:

- repository publication
- first release
- major feature release
- external article publication
- new directory/list inclusion
- meaningful independent backlink or mention

## Evaluation

Compare rolling 28-day windows. Do not attribute a ranking change to a single GitHub link. Search rankings are affected by many factors; the useful question is whether the combined product, content and external-authority work creates a sustained increase in non-brand impressions and positions.
