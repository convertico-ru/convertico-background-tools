Adds a quick Media Library action that opens the Convertico.ru Background Remover workflow.

== Description ==

Version 0.1 is intentionally small: it adds an external action to image attachments in the WordPress Media Library. Automatic file handoff is planned after the Convertico.ru remote-open endpoint is available.

The plugin does not upload media files in the background and does not add analytics.

== Installation ==

1. Create a folder named `convertico-background-tools` in `wp-content/plugins/`.
2. Copy `convertico-background-tools.php` into that folder.
3. Activate the plugin in WordPress.
4. Open Media → Library in list view and look at an image row.
